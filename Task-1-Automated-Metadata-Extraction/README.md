# Task 1: Automated Image/Video Metadata Extraction

## Technologies
- Python
- OpenCV
- YOLOv8
- Scikit-learn

## Features
- Object Detection
- Dominant Color Extraction
- Brightness Analysis
- Contrast Analysis
- Automatic Metadata Generation

## How to Run

```bash
pip install -r requirements.txt
python main.py
```

## Output

The project generates:

- JSON metadata
- Object detection results
- Image analysis
